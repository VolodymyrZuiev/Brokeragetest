Frequently asked questions

Everything you need to know about the product and billing.

What features are included in the Load Board?

The Load Board provides full control over all active shipments. You can view loads split by status (En Route, Delivered, Issue, Invoiced, Paid), filter by key fields, check rates and route info, manage check calls, and handle issue loads or possible claims on a single screen.

Can I manage user access and permissions?

Yes, the Admin Panel allows you to create companies, offices, and departments. You can manage system users, create custom roles, and apply flexible permissions either at the role level or individually per user for precise control.

Does the system track Shippers and Receivers?

Absolutely. The platform maintains a complete database split by regions. You can search by name, address, and coordinates, with automatic coordinate retrieval via Google API for accurate routing and automatic mileage calculation.

Is there a way to block unreliable carriers or customers?

Yes. We have a dedicated Blacklist module split into customers and carriers. It allows you to display the blocking reason, see who added the block, view the count of completed loads, and return the contractor to active status when necessary.

How does Warehouse management work?

You can create and edit warehouse profiles containing full information, including addresses and contact persons. This database is directly integrated with the Load Board and Dispatch, allowing fast access to warehouse details when organizing shipments.

Are advanced analytics provided?

Yes. The Statistics section provides comprehensive analytics, including load volumes, carrier and driver performance, employee productivity, financial metrics across departments, and detailed route/lane analytics.
